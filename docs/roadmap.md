# Roadmap

This roadmap is exploratory. It is not a release commitment.

## v0.1.x

- Improve error messages
- Expand conformance fixtures
- Add CI integration examples
- Review schema stability from real usage

## v0.2.x

- Explore a Markdown handoff renderer ✓
- Evaluate a versioned extension field only when real shared metadata use cases justify it
- Add adapter examples when real use cases justify them

## Later

- Explore an optional local collector
- Explore an optional static dashboard as a separate package
- Explore optional protocol mappings

A database, dispatcher, and chat bot remain outside the initial package.
